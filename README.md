# COSMOS IDLE

A browser-based incremental universe evolution game. Begin in the earliest moments of the cosmos and guide it through particles, atoms, stars, galaxies and the far future.

## Play

Open [COSMOS IDLE](https://gggggggggggggggg312.github.io/cosmos-idle/) after enabling GitHub Pages for this repository, or open `index.html` locally in a modern browser.

## Features

- **Evolving universe view:** a live cosmic visualization changes as the universe passes through different stages.
- **Universe properties:** track simulated age, temperature, scale factor, expansion and matter composition.
- **Cosmic resources:** collect energy, particles, matter, hydrogen, helium, metals, stars and galaxies.
- **Cosmic processes:** build processes that generate resources over time, from quantum fluctuations to galaxy formation.
- **Research:** unlock production, progression, gravity and stellar improvements.
- **21 cosmic eras:** progress from the Planck Epoch through the speculative far-future Dark Era.
- **Cosmic events:** temporary events such as supernova bursts and energy surges boost production.
- **Achievements:** earn milestones for reaching important stages and resource goals.
- **Encyclopedia:** review the eras and their simplified descriptions.
- **Cosmic Legacy:** reach the Dark Era and start a new universe with a permanent production bonus.
- **Autosave:** progress is stored locally in the browser.

## Run locally

Download or clone the repository and open `index.html` in a modern browser. No build tools or external dependencies are required.

## Notes

This is a playful, simplified game inspired by cosmology, not a scientific simulation. Era boundaries, resource rates, the visualization and the far-future scenarios are simplified for gameplay. The universe age shown is simulated game time, not a conversion of the real cosmic timeline.
